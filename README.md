# 环境配置规则与知识库

一个用于收集和维护环境配置要求与开发知识文档的仓库。

## 项目目的

在开发过程中，我们经常需要配置各种开发环境（编程语言、框架、工具等），同时需要记录和分享相关的知识文档（如Skills写法、Memory系统使用等）。本项目旨在：

1. **环境配置要求**：收集各种技术栈的环境配置说明，包括：
   - 系统要求（操作系统、版本）
   - 依赖安装（包管理器、命令行工具）
   - 配置步骤
   - 常见问题解决方案

2. **知识文档集合**：整理开发相关的知识文档，包括：
   - Claude Code 开发技巧
   - Skills 编写指南
   - Memory 系统使用说明
   - 其他开发最佳实践

## 项目结构

```
env_rules/
├── README.md               # 项目说明（本文档）
├── environment_rules/      # 环境配置规则目录
│   ├── python/            # Python 环境配置
│   ├── nodejs/            # Node.js 环境配置
│   ├── docker/            # Docker 环境配置
│   ├── langchain/         # LangChain 环境配置
│   └── ...                # 其他技术栈
└── knowledge_base/        # 知识文档集合目录
    ├── claude_code/       # Claude Code 相关文档
    │   ├── skills/        # Skills 编写指南
    │   ├── memory/        # Memory 系统使用
    │   └── ...            # 其他 Claude Code 功能
    ├── development/       # 开发相关知识
    └── best_practices/    # 最佳实践文档
```

## 如何使用

### 1. 查找环境配置

进入 `environment_rules/` 目录，找到对应的技术栈文件夹，查看相关配置说明。

### 2. 查阅知识文档

进入 `knowledge_base/` 目录，根据分类查找需要的文档。

### 3. 添加新内容

欢迎贡献新的环境配置规则或知识文档：

1. Fork 本仓库
2. 在相应目录下创建新的文档
3. 提交 Pull Request

## 贡献指南

1. **环境配置规则**：
   - 请使用 Markdown 格式编写
   - 包含清晰的操作步骤
   - 注明适用的操作系统和版本
   - 提供验证配置是否成功的方法

2. **知识文档**：
   - 结构清晰，易于阅读
   - 提供实际示例
   - 保持文档的时效性

3. **提交规范**：
   - 提交信息请使用中文或英文
   - 说明添加/修改的内容
   - 关联相关 Issue（如果有）
