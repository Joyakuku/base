# env_rules

用于维护两类文档：

- **环境规则**：技术栈环境搭建、验证、排障
- **知识文档**：可复用的方法论与操作规范

---

## 快速导航

- 环境规则入口：[`environment_rules/README.md`](./environment_rules/README.md)
- 知识文档入口：[`knowledge_base/README.md`](./knowledge_base/README.md)

---

## 使用方式

1. 先进入对应目录的 `README.md`，查看该目录统一格式。
2. 按格式阅读已有文档，优先使用“最小可用步骤”。
3. 新增或修改文档时，保持与目录规范一致。

---

## 贡献约定（精简）

- 文档统一使用 Markdown。
- 内容以“可执行、可验证、可维护”为准。
- 未确认的信息先预留空位，不强行补全。
