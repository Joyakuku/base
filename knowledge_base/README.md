# 知识库目录

本目录存放开发相关的知识文档集合。

## 目录结构

建议按以下分类组织文档：

- `claude_code/` - Claude Code 相关文档
  - `skills/` - Skills 编写指南
  - `memory/` - Memory 系统使用说明
  - `hooks/` - Hooks 配置指南
  - `agents/` - Agents 使用指南
- `development/` - 通用开发知识
  - `git/` - Git 使用技巧
  - `docker/` - Docker 最佳实践
  - `ci_cd/` - CI/CD 配置
- `best_practices/` - 开发最佳实践
  - `code_quality/` - 代码质量
  - `security/` - 安全最佳实践
  - `performance/` - 性能优化

## 文档规范

1. **标题明确** - 清晰说明文档主题
2. **结构清晰** - 使用目录、标题层级
3. **内容实用** - 提供实际可操作的指导
4. **示例丰富** - 包含代码示例或配置示例
5. **保持更新** - 定期更新确保信息准确

## 贡献指南

欢迎添加新的知识文档，建议：

1. 选择合适的分类目录
2. 创建结构清晰的 Markdown 文档
3. 提供实际示例和参考资料
4. 保持文档的时效性和准确性
